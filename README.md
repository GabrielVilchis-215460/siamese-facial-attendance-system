# siamese-facial-attendance-system
Este repositorio corresponde al desarrollo del prototipo de mi tesis titulado: "Sistema de Asistencia Laboral Mediante Reconocimiento Facial con Redes Siamesas y Analítica de Comportamiento de Asistencia". Contiene todo el codigo correspondiente al backend y frontend, asi como el notebook utilizado para los modelos de reconocimiento facial.
